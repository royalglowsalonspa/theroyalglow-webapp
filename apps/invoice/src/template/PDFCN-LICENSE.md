# pdfcn Takumi components

The invoice template adapts the Takumi Invoice Classic block and its Table and Divider components from [pdfcn at `1f0cd8adac3196fbbd01ada1841a24a758f450a1`](https://github.com/shadcn-labs/pdfcn/tree/1f0cd8adac3196fbbd01ada1841a24a758f450a1/apps/web/registry/bases/takumi). The adaptation uses the Worker’s HTML input and Royal Glow’s invoice data and typography.
