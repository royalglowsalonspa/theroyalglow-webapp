# API Reference

The Royal Glow API is a set of Next.js route handlers under `/api`. All
endpoints share one JSON envelope, human-readable RESTful paths, and stable
error codes — so both browsers and AI agents can call them predictably.

<Callout type="info">
  This reference is hand-authored from the actual route handlers and the shared
  Zod schemas in `packages/types`. It reflects the code at authoring time; when
  a route's schema changes, update the corresponding page (or regenerate this
  section).
</Callout>

## Base & envelope

- **Base URL:** `https://theroyalglow.in` (local: `http://localhost:3000`)
- **Success:** `{ "success": true, "data": <T>, "meta"?: {...} }`
- **Error:** `{ "success": false, "error": { code, message, statusCode, requestId, retryable?, details? } }`

See [Conventions](/docs/conventions) for the full envelope, money/date rules,
and the error-code table, and [Authentication](/docs/authentication) for the
session/role model.

## Authentication

Most endpoints require a Better Auth session cookie. Each endpoint below notes
its **minimum role**. Public endpoints need no auth: `GET /api/services`,
`GET /api/services/[slug]`, `GET /api/availability`, `POST /api/leads`,
`GET /api/health`.
