These endpoints expose the public service catalogue, the branches taking
bookings, and the booking-slot schedule. All four are **Public** — none of them
call `requireSession` or `requireRole`, so no session cookie is needed.

<Info>
  **Base URL:** `https://theroyalglow.in` · **Auth:** Public (no session). Money
  is an integer in **paise** (`pricePaise: 250000` = ₹2,500.00). Durations are
  whole minutes. All responses use the standard envelope
  `{ "success": true, "data": ... }`.
</Info>

## GET /api/services

Returns the full catalogue: every active service category (ordered by
`displayOrder`) with its active services nested under `services`.

**Minimum role:** Public

```http
GET /api/services
```

This endpoint takes no path or query parameters.

### Response

`data.categories` is an array of active categories, each with a `services` array
of its active services in display order.

Each service says where it is offered. `availableBranchIds` is `null` when
every branch offers it, branches opened later included; otherwise it lists the
branch ids that do. A service is offered at a branch only when its own setting
and its category's both include the branch. `availabilityNote` is the text the
website shows for a restricted service ("Only at Rayasandra",
"Only at Marathahalli and Rayasandra"), naming branches from
`GET /api/branches` only; it is `null` for a service every branch offers, and
"Not offered at any branch right now" when none of its branches is public.

```json
{
  "success": true,
  "data": {
    "categories": [
      {
        "id": "cat_vvipspa01",
        "name": "VVIP SPA Service",
        "serviceType": "spa",
        "displayOrder": 9,
        "services": [
          {
            "id": "svc_swedish001",
            "categoryId": "cat_vvipspa01",
            "categoryName": "VVIP SPA Service",
            "serviceType": "spa",
            "name": "Swedish Massage",
            "slug": "swedish-massage",
            "durationMinutes": 60,
            "pricePaise": 250000,
            "gemsRedeemable": false,
            "gemsRequired": null,
            "availableBranchIds": null,
            "availabilityNote": null
          },
          {
            "id": "svc_hotstone01",
            "categoryId": "cat_vvipspa01",
            "categoryName": "VVIP SPA Service",
            "serviceType": "spa",
            "name": "Hot Stone Therapy",
            "slug": "hot-stone-therapy",
            "durationMinutes": 90,
            "pricePaise": 450000,
            "gemsRedeemable": true,
            "gemsRequired": 500,
            "availableBranchIds": ["br_rayasandra01"],
            "availabilityNote": "Only at Rayasandra"
          }
        ]
      }
    ]
  }
}
```

## GET /api/services/[slug]

Returns a single service matched by its unique `slug`.

**Minimum role:** Public

```http
GET /api/services/signature-haircut
```

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `slug` | `string` | Yes | Path. The service's unique slug (e.g. signature-haircut). |

### Response

An inactive service is not found. `availableBranchIds` is `null` when every
branch offers the service, otherwise the branch ids that do; this endpoint has
no `availabilityNote`.

```json
{
  "success": true,
  "data": {
    "service": {
      "id": "svc_haircut001",
      "categoryId": "cat_haircare01",
      "categoryName": "Haircut & Styling",
      "serviceType": "salon",
      "name": "Signature Haircut",
      "slug": "signature-haircut",
      "description": "Consultation, wash, cut, and style",
      "durationMinutes": 45,
      "pricePaise": 80000,
      "gemsRedeemable": false,
      "gemsRequired": null,
      "availableBranchIds": null
    }
  }
}
```

### Errors

<AccordionGroup>
<Accordion title="NOT_FOUND — 404">

No service exists for the given `slug`.

</Accordion>
<Accordion title="INTERNAL_ERROR — 500">

Unexpected/transient failure. `retryable: true`.

</Accordion>
</AccordionGroup>

## GET /api/branches

Returns the branches the booking dialog's branch picker shows: every branch
that is not shut down, in display order, and the branch to preselect. Each
branch carries only its id, name, city, and status, plus whether it is taking
bookings; address, phone, and coordinates are not exposed.

**Minimum role:** Public

```http
GET /api/branches
```

This endpoint takes no path or query parameters.

### Response

Only an `operational` branch has `acceptingBookings: true`; the picker shows the
others disabled. `defaultBranchId` is the primary branch when it is operational,
otherwise the first operational branch in display order, and `null` when no
branch is taking bookings. `GET /api/availability` uses the same branch when a
request names none.

```json
{
  "success": true,
  "data": {
    "branches": [
      {
        "id": "br_rayasandra01",
        "name": "Rayasandra",
        "city": "Bengaluru",
        "status": "operational",
        "acceptingBookings": true
      },
      {
        "id": "br_marathahalli01",
        "name": "Marathahalli",
        "city": "Bengaluru",
        "status": "opens_soon",
        "acceptingBookings": false
      }
    ],
    "defaultBranchId": "br_rayasandra01"
  }
}
```

### Errors

<AccordionGroup>
<Accordion title="INTERNAL_ERROR — 500">

Unexpected/transient failure (e.g. database unreachable). `retryable: true`.

</Accordion>
</AccordionGroup>

## GET /api/availability

Returns the time slots a customer can request on a date at a branch: a 30-minute
grid across that branch's opening hours that day. Each branch has its own
opening hours, lead time and booking window, which the Developer sets under
Settings. A slot is `available: false` when it starts sooner than the branch's
lead time from now (IST) or, with `durationMinutes`, when a booking that long
would run past closing. The slots are a request grid, not a promise of free
staff, and they don't depend on which services a branch offers: the booking
dialog lists only the chosen branch's services, and `POST /api/bookings` refuses
the rest.

**Minimum role:** Public

```http
GET /api/availability?date=2026-11-15&branchId=br_rayasandra01&durationMinutes=90
```

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `date` | `string` | Yes | Query. Calendar date in YYYY-MM-DD format. Must be a real date and not earlier than today (compared in IST, UTC+5:30). |
| `branchId` | `string` | No | Query. A branch id from `GET /api/branches`; the branch must exist and be operational. When omitted, the slots are for that endpoint's `defaultBranchId`. |
| `durationMinutes` | `integer` | No | Query. How long the booking runs, 1–720. Without it every slot is judged as one 30-minute slot. |

### Response

`notice` says why a day has no slots when the branch is closed that weekday or
the date is beyond its booking window ("Rayasandra is closed on Mondays.",
"Rayasandra takes bookings up to 30 days ahead."), and `slots` is then empty;
otherwise it is `null`. On a holiday or closure, `closure` names it and every
slot is `available: false`; otherwise `closure` is `null`.

```json
{
  "success": true,
  "data": {
    "slots": [
      { "startTime": "10:00", "endTime": "10:30", "available": false },
      { "startTime": "10:30", "endTime": "11:00", "available": true },
      { "startTime": "19:30", "endTime": "20:00", "available": false }
    ],
    "closure": null,
    "notice": null
  }
}
```

### Errors

<AccordionGroup>
<Accordion title="VALIDATION_ERROR — 400">

`date` is missing, not `YYYY-MM-DD`, not a real calendar date, or in the past;
`branchId` is present but empty; `durationMinutes` is not a whole number from 1
to 720; the named branch does not exist (`Branch not found.`) or is not
operational (`Selected branch is not accepting bookings.`); or no `branchId`
was sent and no branch is taking bookings
(`No branch is taking bookings right now.`).

</Accordion>
<Accordion title="BRANCH_SETTINGS_INCOMPLETE — 409">

The branch has no valid booking settings. Nothing falls back to defaults; the
Developer sets them under Settings.

</Accordion>
<Accordion title="INTERNAL_ERROR — 500">

Unexpected/transient failure. `retryable: true`.

</Accordion>
</AccordionGroup>
