# Pages & Routes

The platform has ~104 pages across four route groups plus the admin portal, staff portal, and API layer.

## Route Groups

Next.js App Router uses route groups (folders in parentheses) to share layouts without affecting the URL:

| Group | URL Pattern | Layout | Auth |
| --- | --- | --- | --- |
| `(customer)` | `/`, `/services`, `/bookings`, etc. | Header + footer + nav | Optional |
| `(auth)` | `/sign-in`, `/onboarding` | Minimal centered card | — |
| `(landing)` | `/book` | No nav — conversion-optimised | — |
| `(legal)` | `/privacy`, `/terms`, `/refund-policy` | Minimal | — |
| `admin/` | `/admin/*` | Sidebar + RBAC | Required (receptionist+) |
| `staff/` | `/staff/*` | Minimal | Required (staff+) |
